# CS-230_Operating_Platforms

### The Gaming Room Software Design Template

This project involved designing an initial software design document for a client (The Gaming Room). In this scenario the company wanted to build or complete a distributed application, Draw It or Lose It. The application was a web-based game that resembled the game Pictionary.

I believe I gave good pointers and keywords within my document to help give an awareness toward what to lookout for and what to consider. The design document gives a heads-up about zero-to-many elements which would probably be best to implement early on before the code becomes too unwieldy. One part in the document I think I would like to revise would have to be the incorporation of design ideas and elements that would be used in stand alone applications on the client side. The application on the client side is suppose to be within a browser and this is easier to manage across platforms.

It is a good idea to always have a thorough plan on how to deal with user information. This should probably be one of the first features to establish and to maintain in a mindful way. The needs of the user should be placed at highest priority.

Designing software is a step-by-step process. In designing an application I like to break it up into parts and make sure the difficult areas have been fully worked out and all the components are ready to be put together like a Lego set. I think each application well have its own optimal design route and a software design template is a neat computer-less way of programming software.
